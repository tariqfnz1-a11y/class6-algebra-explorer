📖 Algebra Study Notes

What is Algebra?

Algebra uses numbers, letters and symbols to represent mathematical relationships.

Variable

A variable is a letter or symbol used to represent a number.

Example: x + 4

Constant

A constant is a number whose value does not change.

Example: In x + 7, 7 is a constant.

Coefficient

A coefficient is the number multiplied by a variable.

Example: In 5x, 5 is the coefficient.

Like Terms

Terms containing the same variable are called like terms.

Example: 3x and 2x

Simplifying

Like terms can be combined.

3x + 2x = 5x

Remember

  • A letter can represent a number.
  • Numbers without variables are constants.
  • Like terms can be combined.
  • Always look for the pattern or rule.
