📚 Interactive Study Notes

🔤 Variables & Constants
A variable represents an unknown or changing value. A constant is a number whose value does not change. Example: 3x + 5 3 = coefficient x = variable 5 = constant
🧩 Expressions
An algebraic expression contains numbers, variables and operations. Example: 4x + 7 An expression does not contain an equality sign.
➕ Like Terms
Like terms contain the same variable raised to the same power. 3x + 4x = 7x
⚖️ Equations
An equation states that two expressions are equal. Example: 2x + 4 = 14 Both sides must remain balanced.
🔢 Substitution
Substitution means replacing a variable with a known value. If x = 5: 3x + 2 becomes: 3(5) + 2 = 17
🔍 Patterns
Algebra can describe patterns. Example: 2, 5, 8, 11... The rule is +3.
📈 Coordinates
Coordinates are written as: (x,y) The x-coordinate tells horizontal position. The y-coordinate tells vertical position.
