📚 Study Notes expand to learn

🔤 Variables & Constants
A variable represents an unknown or changing value (e.g. x).
A constant is a fixed number (e.g. 5).
In 3x + 5, 3 is the coefficient, x is the variable, and 5 is the constant.
🧩 Expressions
An algebraic expression contains numbers, variables, and operations — but no equals sign.
Example: 4x + 7
➕ Like Terms
Like terms have the same variable raised to the same power.
3x + 4x = 7x   ✅
3x + 4y   ❌ (different variables)
⚖️ Equations
An equation states that two expressions are equal.
Example: 2x + 4 = 14
Both sides must remain balanced.
🔢 Substitution
Substitution means replacing a variable with a known value.
If x = 5, then 3x + 2 becomes 3(5) + 2 = 17.
🔍 Patterns
Algebra describes patterns.
2, 5, 8, 11, …   The rule is +3.
📈 Coordinates
Coordinates are written as (x, y).
The x value tells horizontal position; the y value tells vertical position.
