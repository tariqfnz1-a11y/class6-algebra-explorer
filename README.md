# Class 6 Algebra Explorer

An interactive mathematics learning prototype for Class 6 students covering basic algebraic concepts.

## Topics

- Number patterns and sequences
- Variables
- Algebraic expressions
- Constants and coefficients
- Like terms
- Simplifying expressions
- Study notes
- 15-question interactive quiz

## Features

- Interactive learning activities
- Instant feedback
- 15-question MCQ quiz
- Responsive design
- Mobile, tablet and desktop friendly
- Simple learner-focused interface
- Designed for classroom and independent learning

## Technology

This project uses:

- HTML5
- CSS3
- JavaScript
- GitHub Pages
- AI-assisted coding / vibe coding

## Purpose

The project explores how educators can use AI-assisted coding to create simple, subject-specific digital learning resources.

## Status

Prototype — Version 1

Further development will include:

- More interactive algebra simulations
- Drag-and-drop activities
- Visual algebra models
- More practice questions
- Teacher resources
- Improved accessibility
